# 白板主界面

## 界面布局

底部三个浮动面板：

- **左下角**：最小化（缩到桌面浮窗）、更多菜单
- **中间**：工具栏（移动 / 书写 / 荧光 / 擦除 / 选择 / 插入 / 填色 / 撤销 / 恢复）
- **右下角**：页码导航（上一页 / 页码 / 下一页 / 添加页）

> 浮动面板区域不落笔：笔迹到面板边缘自动停住，面板两侧与上方正常书写。

## 工具与二级面板

选中工具后，对应选项在工具栏上方弹出二级面板：

| 工具 | 二级面板内容 |
|------|-------------|
| 书写 / 荧光 | 颜色色点、笔迹粗细滑块、粗细预览 |
| 擦除 | 橡皮大小滑块（指示圈同步缩放）、滑动清空本页 |
| 插入 → 形状 | 直线 / 箭头 / 矩形 / 圆形 / 三角形，附颜色粗细 |
| 选择 | 无（直接框选、拖动、删除） |

- 白板（浅色板面）橡皮圈为深色，黑板（深色板面）自动反白，始终看得清。
- 「滑动清空本页」：按住滑块从左拖到右，确认清空当前页，防止误触。

## 插入内容

- **形状**：五种矢量形状，可改颜色粗细
- **三维几何体**：插入可旋转的三维几何示意
- **函数图像**：输入表达式与参数生成函数曲线；选择工具下**双击**已有图像可重新编辑
- **图片**：原始字节内嵌进存档，随白板一起保存

## 页面与视图

- 页码导航翻页、加页；「更多 → 删除本页…」删除当前页
- 双指缩放、移动工具拖动视野；Ctrl+滚轮同样可缩放
- 「更多 → 显示点阵」开关点阵背景
- 「更多 → 适应内容 (Ctrl+1)」缩放到内容范围，「重置视图 (Ctrl+0)」回到 100%

## 文件

| 操作 | 入口 |
|------|------|
| 打开白板 | 更多 → 打开白板…（Ctrl+O） |
| 保存白板 | 更多 → 保存白板…（Ctrl+S） |
| 导出图片 | 更多 → 导出当前页为 PNG… |

- 存档格式为 `.setb`，包含全部页面、笔迹与内嵌图片
- 有未保存修改时标题栏显示 `*`，退出/打开其他文件会先确认
