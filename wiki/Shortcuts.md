# 快捷键

## 白板主界面

### 工具切换

| 按键 | 工具 |
|------|------|
| `V` | 选择 |
| `M` | 移动 |
| `P` | 画笔 |
| `H` | 荧光笔 |
| `E` | 橡皮 |
| `L` | 直线 |
| `A` | 箭头 |
| `R` | 矩形 |
| `O` | 圆形 |
| `T` | 三角形 |

### 编辑与文件

| 按键 | 功能 |
|------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Delete` / `Backspace` | 删除选中内容 |
| `Ctrl+S` | 保存白板 |
| `Ctrl+O` | 打开白板 |

### 视图与页面

| 按键 | 功能 |
|------|------|
| `Ctrl + +` | 放大 |
| `Ctrl + -` | 缩小 |
| `Ctrl+0` | 重置视图（100%） |
| `Ctrl+1` | 缩放到适应内容 |
| `PageUp` / `PageDown` | 上一页 / 下一页（带翻页动画） |
| `F11` | 全屏切换 |
| `Esc` | 全屏时退出全屏；否则切回选择工具 |

## 桌面批注层

| 按键 | 功能 |
|------|------|
| `Esc` | 关闭批注层返回浮窗 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |

## 鼠标与触摸

- **双指**：缩放 / 平移画布
- **Ctrl + 滚轮**：缩放
- **鼠标右键拖动**：临时橡皮
- **选择工具双击函数图像**：重新编辑表达式与参数
