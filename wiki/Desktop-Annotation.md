# 桌面批注与悬浮窗

## 悬浮窗

最小化白板后，桌面出现常驻小浮窗（两个图标按钮）：

- **批注**：进入全屏桌面批注层
- **返回白板**：恢复白板主界面

浮窗始终置顶，不抢焦点，可随意拖动位置。

## 桌面批注层

在任意内容（PPT、网页、视频）上直接书写：

- 主行工具：**穿透** / 画笔 / 荧光笔 / 橡皮 / 选择 / 填色 / 图形 / 撤销 / 重做 / 清除 / 退出
- **颜色、粗细、预览收进二级面板**：选中画笔等工具时在上方展开，点击画布自动收起，带淡入淡出 + 上浮动画
- **橡皮**有独立大小滑块；批注层背景透明，橡皮圈用黑白双描边，任何底色上都清晰
- 「图形」按钮展开形状二级菜单，选中形状工具后按钮高亮
- `Esc` 或「退出」关闭批注层返回浮窗；`Ctrl+Z` / `Ctrl+Y` 撤销重做
- 工具栏区域不落笔，二级面板展开时禁区自动上移

## 穿透工具

选中「穿透」（鼠标指针图标）后：

- **笔迹全部保留显示**，画布不再接收鼠标/触摸，可直接点击下层窗口（翻 PPT、操作网页等）
- **工具栏是独立小窗口，始终可见可点**，不会被穿透
- **选择任意其他工具即退出穿透**，恢复书写；进入穿透时二级面板自动收起

## PPT 模式

在「更多 → PPT 模式」开关（默认开启）。通过 COM 检测正在运行的 PowerPoint / WPS 演示：

| 时机 | 行为 |
|------|------|
| 开始放映 | 白板主界面自动收起 → 进入桌面批注 → 自动穿透，可直接点 PPT 翻页 |
| PPT 翻页 | 笔迹按幻灯片页码保存/恢复：上一页笔迹隐藏但保留，回到该页原样恢复，新页是空白层 |
| 结束放映 | 自动退出穿透，恢复批注工具栏，笔迹保留 |

- **翻页浮钮**：屏幕左下、右下角各有一组「‹ ›」半透明圆形按钮，不穿透、随时可点；点击立即切批注页并与 PPT 核对页码，无轮询延迟
- PPT 模式下**禁止缩放/平移视图**，笔迹始终与幻灯片对齐
- 点批注栏「退出」会**自动结束放映**再关闭批注层

> 需要完整安装的 PowerPoint 或 WPS 演示；批注页码与幻灯片页码 1:1 对应。

## 置顶机制

浮窗与批注层使用 Win32 `SetWindowPos(HWND_TOPMOST)` 置顶，并在失焦、激活及定时复查时持续保持，尽量压过其他置顶窗口（如教学软件全屏界面）。

> 若仍被个别带显示驱动层的电子白板软件盖住，需在对方软件中关闭「全屏置顶」类选项，普通进程无法突破驱动级覆盖。

## 进程守护（防误退出）

SETBoard 带双进程互守：

- 主进程被杀 → 守护进程自动重新拉起
- 守护进程被杀 → 主进程自动重建
- 点 X、Alt+F4、任务栏关闭 → 转为最小化到浮窗，不会退出

**唯一退出方式**：白板「更多 → 退出 SETBoard…」（未保存内容会先确认）。

卸载或更新前请用官方卸载脚本 / 内置更新，它们会先通知守护进程再结束进程，避免被复活。
